<h1>🌙 WHMCS Admin Dark Mode</h1>

<p><strong>WHMCS Admin Dark Mode</strong> is a free and lightweight addon that enables you to toggle between light and dark themes in your WHMCS Admin Area.  
It includes customization options like brightness, sepia, contrast, and auto mode synced with your system preferences.</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>🌙 One-click toggle between light and dark mode</li>
  <li>🔆 Adjustable brightness</li>
  <li>🟤 Optional sepia tone effect</li>
  <li>🎚️ Contrast customization for readability</li>
  <li>⚙️ Auto Mode (switches based on system settings)</li>
  <li>🖥️ Works with all WHMCS Admin Themes (including Blend)</li>
</ul>

<h2>🛠️ Installation Guide</h2>

<h3>Step 1: Download</h3>
<p>Download the latest version of the Dark Mode addon.</p>

<h3>Step 2: Upload Files</h3>
<p>Upload the <code>darkmode</code> folder into:</p>
<pre>/modules/addons/darkmode</pre>

<h3>Step 3: Activate Module</h3>
<p>In WHMCS Admin → <strong>Setup &gt; Addon Modules</strong>, activate <strong>Dark Mode</strong>.</p>

<h3>Step 4: Configure</h3>
<p>Set brightness, sepia, contrast, or enable auto mode in settings.</p>
